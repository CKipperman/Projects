# The Eatery – Restaurant Website

A multi-page static website for a fictional breakfast restaurant called **The Eatery**.  
This project was built as practice to improve HTML and CSS skills.

## About the Project

The website includes three main pages:

- **Home** (`index.html`) – Introduction to the restaurant and its story
- **Menu** (`menu.html`) – Featured items, descriptions, images, and a daily specials table
- **About Us** (`about.html`) – Restaurant information, promotional video, and a customer feedback form

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive design with media queries

## Features Practiced

- Semantic HTML structure
- Multi-page navigation
- CSS layout techniques (floats, positioning, flex-like alignment)
- Responsive design for mobile screens
- Styled tables (daily specials)
- Form styling and basic validation attributes
- Custom fonts and color schemes
- Image and video embedding
- Hover and active states
- Media queries for smaller screens

## Project Structure
TheEatery/
├── index.html
├── menu.html
├── about.html
├── restaurant.css      # Main shared styles
├── menu.css            # Menu-specific styles
└── images/             # Photos, logo, video, favicons


## How to View

1. Download or clone the repository
2. Open `index.html` in any modern web browser
3. Navigate between the pages using the menu

No build tools or server required — it runs fully as static files.

## Purpose

This project was created to practice and demonstrate fundamental front-end skills in HTML and CSS, with a focus on clean structure, visual design, and responsiveness.
