# Basic Bootstrap Website

A simple, responsive one-page website built with HTML and Bootstrap 5.

## About the Project

This project is a clean, modern website template that includes a navigation bar, hero section, services cards, about section, contact form, and footer. It was created as practice for learning and using the Bootstrap framework.

## Technologies Used

- HTML5
- Bootstrap 5.3.3 (via CDN)
- Bootstrap Icons / JavaScript components (navbar toggler)

## Features Practiced

- Responsive navbar with collapse functionality
- Bootstrap grid system (`row` + `col-md-4`)
- Card components
- Form controls and styling
- Utility classes (spacing, colors, text alignment)
- Fixed-top navigation
- Responsive layout that works on mobile and desktop

## Sections Included

- **Navbar** – Fixed dark navigation with links
- **Hero** – Welcome section with call-to-action button
- **Services** – Three service cards in a responsive grid
- **About** – Short about section
- **Contact** – Contact form
- **Footer** – Simple copyright footer

## Project Structure
BootstrapWebsite/
└── bootstrap.html


## How to View

1. Open `bootstrap.html` in any modern web browser.
2. Resize the browser window to see the responsive behavior.

No installation or build tools required — everything loads from the Bootstrap CDN.

## Purpose

This project was built to practice using Bootstrap’s components, grid system, and utility classes to create a clean and responsive website quickly.
