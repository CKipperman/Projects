# Blog Apps Collection

A collection of two blog-style applications that display users, posts, and comments using data from the JSONPlaceholder API. One version is built with React, and the other with vanilla JavaScript.

## Projects Included

### 1. React Blog (`reactBlog`)
A React application that uses React Router for navigation between users and posts.

**Features practiced:**
- Fetching data from an external API
- React Router (dynamic routes)
- State management with `useState` and `useEffect`
- Component composition
- Show/hide comments functionality

### 2. Vanilla JS Blog (`vanillaBlog`)
The same concept built with plain JavaScript and Vite (no framework).

**Features practiced:**
- Modular JavaScript (ES modules)
- DOM manipulation
- Fetch API
- Event handling
- Separating logic into multiple files (`users.js`, `posts.js`, `comments.js`, etc.)

## Purpose

These projects were created to practice building the same application in two different ways — once with React and once with vanilla JavaScript — to better understand the differences between a framework-based approach and plain JavaScript.
