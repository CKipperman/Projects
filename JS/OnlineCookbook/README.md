# Online Recipe Book

A simple recipe viewer built with vanilla JavaScript that loads recipe data from JSON files.

## About the Project

Users can choose a recipe from a list of radio buttons. When a recipe is selected, the page displays its title, image, ingredients, and instructions. Recipe data is loaded dynamically from external JSON files.

## Technologies Used

- HTML5
- CSS (CSS Grid + Flexbox)
- Vanilla JavaScript
- Fetch API
- JSON

## Features Practiced

- Fetching and parsing JSON data
- Dynamically creating form elements (radio buttons)
- Updating the DOM based on user selection
- Handling asynchronous data loading with `async/await`
- Error handling for failed requests
- Separating data (JSON) from presentation (HTML/JS)
- Using an IIFE for code organization

## How to Use

1. Select a recipe from the available options.
2. The page will display the recipe’s image, ingredients list, and step-by-step instructions.

## How to Run

1. Open `recipes.html` in a modern web browser  
   (or use a local server if loading JSON files requires it).

## Purpose

This project was created to practice working with the Fetch API, loading external JSON data, and dynamically updating the page based on user choices.
