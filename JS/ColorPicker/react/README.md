# React Color Picker

A simple React application that lets users change the background color, text color, and font of a content box in real time.

## About the Project

This project demonstrates controlled form inputs in React. Users can pick a background color, text color, and font family, and the content area updates instantly to reflect their choices.

## Technologies Used

- React
- JSX
- CSS
- HTML color input and select elements

## Features Practiced

- React functional components
- State management with `useState`
- Handling multiple form inputs
- Controlled components
- Passing children/content via props
- Dynamic inline styling

## Components

- `App.jsx` – Main component that provides the content
- `ColorPicker.jsx` – Handles color and font controls and applies the selected styles

## How to Run

1. Install dependencies:
   ```bash
   npm install
2. Start the development server:
   npm run dev

## Purpose

This project was created to practice React state, controlled inputs, and dynamic styling.
