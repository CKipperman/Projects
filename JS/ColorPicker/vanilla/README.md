# Color Picker with History (Vanilla JS)

A simple web page that lets users change the font color and background color, and keeps a history of every change.

## About the Project

Users can select a text color and a background color using color pickers. Each change is recorded in a table with a timestamp. Clicking any row in the history table restores those colors.

## Technologies Used

- HTML5
- CSS
- Vanilla JavaScript

## Features Practiced

- DOM selection and manipulation
- Event listeners (`change` and `click`)
- Updating styles dynamically
- Storing history in an array
- Creating and inserting table rows
- Using an IIFE (Immediately Invoked Function Expression)
- Restoring previous states from history

## How to Run

1. Open `colors.html` in any modern web browser.

No build tools or installation required.

## Purpose

This project was created to practice vanilla JavaScript DOM manipulation, event handling, and maintaining a simple history of user actions.
