# Color Picker Projects

A collection of two color picker applications. One is built with React and the other with vanilla JavaScript.

## Projects Included

### 1. React Color Picker (`reactColorPicker`)
A React app that lets users change the background color, text color, and font of a content box in real time.

**Features practiced:**
- React functional components
- State management with `useState`
- Controlled inputs (color pickers and select)
- Dynamic inline styling
- Passing content via props

### 2. Vanilla JS Color Picker (`vanillaColorPicker`)
A plain JavaScript version that changes font and background colors and keeps a history of every change in a table.

**Features practiced:**
- DOM manipulation
- Event listeners
- Storing history in an array
- Dynamically creating table rows
- Restoring previous color choices
- Using an IIFE

## Purpose

These projects were created to practice building similar interactive color tools in both React and vanilla JavaScript, focusing on state, user input, and dynamic styling.
