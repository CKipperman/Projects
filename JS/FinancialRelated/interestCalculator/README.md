# Interest Calculator

A JavaScript module that calculates compound interest using the module pattern and method chaining.

## Features

- Set interest rate
- Set number of years
- Calculate interest earned on a principal amount
- Basic validation (values must be greater than zero)
- Supports method chaining (e.g. `.setRate().setYears().calculateInterest()`)

## How to Run

1. Open `interestCalculator.html` in a browser, or
2. Run with Node.js:
   ```bash
   node interestCalculator.js

## Purpose

This project was created to practice:
- The Module Pattern (IIFE)
- Encapsulation of private variables
- Method chaining
- Basic error handling
