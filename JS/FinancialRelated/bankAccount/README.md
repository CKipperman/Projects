# Bank Account

A small JavaScript project that demonstrates creating bank account objects and managing balances.

## Features

- Create multiple independent accounts
- Set and get account balance
- Perform deposits and withdrawals
- Practice using `call` and `bind` to control the value of `this`

## How to Run

1. Open `bankAccount.html` in a browser, **or**
2. Run the file with Node.js:
   ```bash
   node bankAccount.js

Results will appear in the browser console or terminal.

## Purpose
This project was created to practice JavaScript object methods and the this keyword, including explicit binding with call and bind.
