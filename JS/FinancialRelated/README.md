# Financial-Related JavaScript Projects

A collection of small JavaScript projects focused on practicing core language features, object-oriented concepts, and financial calculations.

## Projects Included

### 1. Bank Account
Practices object creation, methods, and the use of `call` and `bind`.
- Create accounts
- Set and get balance
- Perform deposits and withdrawals
- Demonstrates `this` binding techniques

### 2. Credit Card Payoff Simulator
Simulates how long it takes to pay off two different credit cards and the total amount paid.
- Calculates interest and monthly fees
- Compares two card scenarios

### 3. Interest Calculator
Uses the module pattern (IIFE) and method chaining to calculate compound interest.
- Set interest rate and number of years
- Calculate interest on a principal amount
- Includes basic input validation

### 4. React Calculator
A fully functional calculator built with React (class components).
- Supports basic arithmetic operations
- Includes clear, delete, and decimal functionality
- Uses component composition (DigitBtn, OperatorBtn, ActionBtn)

## Purpose

These projects were created to practice:
- JavaScript objects and methods
- `this`, `call`, and `bind`
- Module pattern and encapsulation
- Basic financial formulas
- React component structure and state management
