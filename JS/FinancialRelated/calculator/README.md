# React Calculator

A fully functional calculator built with React using class components.

## Features

- Basic arithmetic operations (`+`, `-`, `*`, `÷`)
- Decimal support
- Clear (AC) and Delete (DEL) functions
- Display of previous and current operands
- Component-based structure

## Components

- `App.jsx` – Main calculator logic and state
- `DigitBtn.jsx` – Number buttons
- `OperatorBtn.jsx` – Operator buttons
- `ActionBtn.jsx` – AC, DEL, and decimal buttons

## How to Run

1. Install dependencies (if needed):
   ```bash
   npm install
2. Start the development server:
    npm run dev

## Purpose

This project was created to practice React class components, state management, and component composition.
