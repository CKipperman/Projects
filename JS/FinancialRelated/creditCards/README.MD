# Credit Card Payoff Simulator

A JavaScript script that calculates how long it takes to pay off a credit card and the total amount paid.

## What It Does

Compares two credit card scenarios:

- **Stellar Horizon Visa** – Higher minimum payment + monthly fee
- **Vortex Elite Mastercard** – Lower minimum payment, no monthly fee

For each card it shows:
- Number of months to pay off
- Total amount paid (including interest and fees)

## How to Run

-   ```bash
    node creditCards.js

## Purpose

This project was created to practice loops, financial calculations, and working with real-world style data in JavaScript.
