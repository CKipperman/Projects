# Video Player

A simple custom video player built with vanilla JavaScript that loads a list of videos from a JSON file.

## About the Project

Users can browse a sidebar list of videos and click any item to play it in the main video player. Each video can have a title, source URL, and optional thumbnail image. Video data is loaded dynamically from an external JSON file.

## Technologies Used

- HTML5
- CSS (CSS Grid)
- Vanilla JavaScript
- Fetch API
- JSON
- HTML5 Video element

## Features Practiced

- Fetching and parsing JSON data
- Dynamically creating a list of video items
- Controlling an HTML5 `<video>` element with JavaScript
- Handling click events to switch videos
- Setting video source, poster image, and auto-playing
- Error handling for failed data loading
- Using an IIFE for code organization

## How to Use

1. Click any video in the sidebar.
2. The selected video will load and start playing in the main player.

## How to Run

1. Open `videos.html` in a modern web browser  
   (or use a local server if required for loading JSON/media files).

## Purpose

This project was created to practice working with the Fetch API, JSON data, and controlling HTML5 media elements with vanilla JavaScript.
