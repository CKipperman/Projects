# Motivational Quote of the Day – Three Versions

A collection of three implementations of the same “Quote of the Day” application, built with different technologies.

## Projects Included

### 1. React Version
Built with React (JavaScript).  
Focuses on component structure, props, and state management.

### 2. React + TypeScript Version
The same React app rewritten with TypeScript.  
Adds type safety with interfaces for component props.

### 3. Vanilla JS + Vite Version
A framework-free version built with plain JavaScript and Vite.  
Focuses on DOM manipulation and modular JavaScript.

## Shared Features Across All Versions

- Displays a consistent “quote of the day” based on the day of the year
- Shows the current date
- Allows users to generate a random quote
- Uses a local JSON file for quote data
- Uses the `dayjs` library for date handling

## Purpose

These projects were created to practice building the same application in three different ways — React, React with TypeScript, and vanilla JavaScript — to better understand the differences between each approach.
