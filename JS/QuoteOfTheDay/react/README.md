# Motivational Quote of the Day (React)

A React application that displays a motivational quote of the day and allows users to generate random quotes.

## About the Project

The app shows a daily quote based on the current day of the year, along with the current date. Users can also click a button to get a new random quote. Quotes are stored in a local JSON file.

## Technologies Used

- React
- dayjs (for date handling)
- JSON
- CSS

## Features Practiced

- React functional components and props
- State management with `useState`
- Working with external JSON data
- Date formatting with the `dayjs` library
- Component composition
- Generating a consistent “quote of the day” based on the day of the year

## Components

- `App.jsx` – Main component and state management
- `Date.jsx` – Displays the current date
- `QuoteFormat.jsx` – Displays the quote and author
- `NewQuoteBtn.jsx` – Button to load a random quote
- `Quotes.jsx` – Helper functions to get the daily or random quote

## How to Run

1. Install dependencies:
   ```bash
   npm install
2. Start the development server:
   npm run dev

## Purpose

This project was created to practice React component structure, state, and working with dates and external data.
