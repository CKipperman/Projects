# Motivational Quote of the Day (Vanilla JS + Vite)

A simple motivational quote application built with vanilla JavaScript and Vite.

## About the Project

The app displays a “quote of the day” based on the current day of the year, along with the current date. Users can also click a button to get a new random quote. Quotes are stored in a local JSON file.

## Technologies Used

- Vanilla JavaScript (ES Modules)
- Vite
- dayjs (for date handling)
- JSON
- CSS

## Features Practiced

- DOM selection and manipulation
- Event handling
- Working with external JSON data
- Date formatting with the `dayjs` library
- Modular JavaScript (separating quote logic into its own file)
- Generating a consistent “quote of the day” based on the day of the year

## How to Run

1. Install dependencies:
   ```bash
   npm install
2. Start the development server:
   npm run dev

## Purpose

This project was created to practice vanilla JavaScript, working with dates, and loading external data without using a front-end framework.
