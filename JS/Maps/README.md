# Interactive Map Search

A web application that displays an interactive Google Map with search functionality for places and addresses.

## About the Project

Users can search for places (using the Geonames Wikipedia API) or addresses (using Google Geocoding). Search results appear in a sidebar and as markers on the map. Clicking a result or marker shows more information.

## Technologies Used

- HTML5
- CSS (CSS Grid layout)
- Vanilla JavaScript
- Google Maps JavaScript API
- Geonames Wikipedia Search API

## Features Practiced

- Integrating the Google Maps API
- Using Advanced Markers and Info Windows
- Fetching data from external APIs
- Geocoding (address → coordinates)
- Dynamic DOM updates (search results list)
- Handling user input and search events
- Error handling for empty or failed searches
- Switching between different search modes

## How It Works

1. Choose a search type:
   - **Search Places (Wikipedia)** – finds landmarks and locations with summaries and images
   - **Search Addresses (Geocoding)** – finds specific addresses
2. Enter a search term and click the search button
3. Results appear in the sidebar and as markers on the map
4. Click a result or marker to view more details

## How to Run

1. Open `map.html` in a modern web browser.
2. Note: You will need a valid Google Maps API key with the Maps JavaScript API and Geocoding API enabled.

## Purpose

This project was created to practice working with the Google Maps API, external data sources, and building an interactive map-based user interface with vanilla JavaScript.
