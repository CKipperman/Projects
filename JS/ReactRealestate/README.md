# Real Estate Website

A multi-page React application for a fictional real estate company. Users can view featured homes, browse listings for sale, and navigate between pages.

## About the Project

The site includes a home page with an image carousel of featured properties, a “Buy” page that displays available homes in card format, and a “Sell” page. Navigation is handled with React Router, and property data is loaded from a local JSON file.

## Technologies Used

- React
- React Router
- JSON
- CSS

## Features Practiced

- Multi-page routing with React Router
- Nested routes and layout components (`Header`, `Footer`, `Outlet`)
- Displaying data from a JSON file
- Reusable components (`HomeCard`)
- CSS animations (image carousel)
- Responsive card layout for property listings

## Pages

- **Home** – Featured properties carousel and contact information
- **Buy** – Grid of homes available for purchase
- **Sell** – Placeholder page for selling a home

## Components

- `App.jsx` – Main layout with header, footer, and outlet
- `Header.jsx` – Navigation bar
- `Footer.jsx` – Site footer
- `Home.jsx` – Landing page with image carousel
- `BuyHome.jsx` – Listings page
- `HomeCard.jsx` – Individual property card
- `SellHome.jsx` – Sell page

## How to Run

1. Install dependencies:
   ```bash
   npm install
2. Start the development server:
   npm run dev

## Purpose

This project was created to practice React Router, component-based architecture, and building a multi-page website with reusable UI components.
