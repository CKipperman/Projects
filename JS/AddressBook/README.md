# Famous Places Address Book

A simple React application that displays a table of famous locations and their addresses.

## About the Project

This project shows a list of well-known places (such as the White House, U.S. Capitol, and United Nations) in a clean, styled table. Each address is rendered using a reusable React component.

## Technologies Used

- React
- JSX
- CSS

## Features Practiced

- Creating and using functional components
- Passing and receiving props
- Rendering lists of data with components
- Basic table structure in JSX
- Simple CSS styling for tables

## Components

- `App.jsx` – Main component that displays the title and table
- `Address.jsx` – Reusable component that renders a single address row

## How to Run

1. Install dependencies (if needed):
   ```bash
   npm install
2. Start the development server:
   npm run dev

## Purpose

This project was created to practice React fundamentals, especially working with props and reusable components.
