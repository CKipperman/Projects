# Snake Game

A classic Snake game built with HTML5 Canvas and vanilla JavaScript.

## About the Project

Control a snake to eat apples and grow longer. The game increases in speed as your score rises. The game ends if the snake hits the wall or itself. Includes sound effects and a checkered tile background.

## Technologies Used

- HTML5 Canvas
- Vanilla JavaScript
- CSS
- Audio (sound effects)

## Features Practiced

- HTML5 Canvas drawing and animation
- Game loop with `setInterval`
- Keyboard input handling (arrow keys)
- Collision detection (walls and self)
- Object-oriented programming with classes (`Snake`, `Apple`)
- Loading and drawing images
- Playing sound effects
- Dynamic difficulty (speed increases as score grows)
- Responsive canvas sizing

## How to Play

- Use the **arrow keys** to control the snake
- Eat apples to increase your score and grow longer
- Avoid hitting the walls or your own body

## How to Run

1. Open `snake.html` in any modern web browser.

No build tools or installation required.

## Purpose

This project was created to practice game development concepts with the HTML5 Canvas API, including animation, collision detection, and real-time user input.
